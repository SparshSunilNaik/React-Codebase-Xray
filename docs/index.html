02

How one scan runs

The same analyze() call sits behind the dashboard and the CLI. It works through the project in this order, then hands everything to the report builder.

  1. in

    Folder or ZIP

    A ZIP up to 500 MB is unpacked into a temporary folder, and the project root is found by its package.json. Paths with traversal are refused.

  2. 1

    Overview

    Framework, stack, file counts, lines of code and the largest files.

  3. 2

    Import graph

    madge, with your tsconfig, over .ts, .tsx, .js, .jsx, .mjs and .cjs files. node_modules is left out.

  4. 3

    Routes

    Next.js App Router and Pages Router, or React Router.

  5. 4

    Lint

    Your ESLint config when there is one, a React-focused fallback when there is not.

  6. 5

    Packages

    depcheck for unused and missing dependencies.

  7. 6

    Diagnostics, only if asked

    Install, build, test. Skipped unless you opt in.

  8. out

    Report

    The dashboard at localhost:5173, a JSON report, or a Markdown report. Temporary ZIP folders are deleted afterwards.

04

Reading code is safe. Running it is opt-in.

Analysis only reads files. Diagnostics actually executes your project's scripts, so it is off until you turn it on in all the places that matter.

Three switches

  1. A checkbox you tick in the web UI
  2. confirmed: true in the API request
  3. --diagnostics on the CLI

Three commands, nothing else

  • npm install --legacy-peer-deps
  • npm run build
  • npm test -- --passWithNoTests

Each is killed after 5 minutes by default.

Nothing leaves the machine

  • No cloud services or external API calls
  • No accounts and no telemetry
  • ZIPs unpack into an isolated temporary folder
05

Run it locally

Node.js 18 or newer and npm 9 or newer. One command starts the dashboard and its API together.

  1. Clone
    git clone https://github.com/SparshSunilNaik/React-Codebase-Xray.git
cd React-Codebase-Xray
  2. Install
    npm install
  3. Start
    npm run dev
  4. Scan

    Open localhost:5173, paste the absolute path of a React project (try samples/sample-react-app) or upload a ZIP, and press Analyze. The API listens on port 3001.

Good to know

  • Projects past about 10,000 files get slow.
  • Unusual routing setups may not be detected.
  • Nx, Turborepo and Lerna workspaces have partial support.
  • Custom ESLint plugins can trip the lint step.
  • It needs Node.js; it is not a browser extension.

Notes from reading the code

  • The README's clone command still says your-username; use the URL above.
  • The local API enables CORS for every origin and listens on all network interfaces. Any website you visit, or any device on your network, could ask it to scan a path while it runs. Binding to 127.0.0.1 and allowing only the dashboard's origin would close that.
