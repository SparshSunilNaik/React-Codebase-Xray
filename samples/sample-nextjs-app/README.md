# Sample Next.js App

This is a sample Next.js 14 application (App Router) for testing react-codebase-xray.

## Routes

- `/` - Home page
- `/about` - About page
- `/users` - Users list page
- `/users/[id]` - Dynamic user page
- `/api/users` - API route (GET, POST)

## Usage

This fixture can be used to test react-codebase-xray:

```bash
# From the root of react-codebase-xray
npm run dev

# Then analyze this fixture at:
# d:\React Debugger\react-codebase-xray\fixtures\sample-nextjs-app
```
